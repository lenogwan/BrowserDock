> Historical design/audit record. Read [current status](../../../PROGRESS.md) first. Original checkboxes, line numbers, environment limits and proposed fixes below are not a current work queue; use SPECIFICATION for current contracts.

Goal: implement the private vault and usable Windows dock according to SPECIFICATION.md sections 2.1, 2.2, 2.4 and 5 and builder phases 6–7. User authorized both phases.

Architecture: independently tested Rust vault owns zeroizing key/plaintext state, encrypted atomic persistence, inactivity and lockout. Tauri commands expose public bookmarks and authenticated private operations, native window controls, shortcuts and tray. Small Svelte components render a charcoal/mint compact dock with an expandable keyboard search, vault form and settings.

Constraints: loopback only; no remote fonts/assets; no plaintext vault files/logs; Argon2id m=19456 KiB/t=2/p=1, AES-256-GCM salt(16)||nonce(12)||ciphertext/tag; 400x56 collapsed; Escape hide, double Escape within 400ms panic lock; Ctrl+Shift+Space summon and Ctrl+Alt+L panic. Existing no-Git workspace edited in place.

Serialize mutations; check vault status before returning private results. Global panic clears state, hides window; tray offers Show/Hide, Lock, Settings, Exit. Restore/save clamped position, snap to closest screen edge and hover-collapse when auto-hide enabled.
